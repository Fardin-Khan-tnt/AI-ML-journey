# 01. Regression

Predict continuous numerical values using linear and regularized models.

This is the **first step** in supervised learning — understand how to build and evaluate models that predict real numbers.

---

## Key Concepts

- **Ordinary Least Squares (OLS)** — minimize sum of squared errors
- **Gradient Descent** — iteratively update weights
- **Cost Function** — mean squared error (MSE)
- **Multiple Features** — handling more than one predictor
- **Metrics** — R², MAE, RMSE
