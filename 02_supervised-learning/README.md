# Supervised Learning

Models that learn from labeled data — given inputs and known outputs, learn to predict the output for new inputs.

---

## Learning Path

Follow this order as you learn:

| # | Topic | Folder | Description |
|---|---|---|---|
| 1 | [Regression](01_regression/) | `01_regression/` | Linear, polynomial, and other regression models |
| 2 | [Logistic Regression](02_logistic-regression/) | `02_logistic-regression/` | Binary and multiclass classification |
| 3 | [Classification Metrics](03_classification-metrics/) | `03_classification-metrics/` | Precision, recall, F1, confusion matrix, ROC-AUC |
| 4 | [KNN](04_knn/) | `04_knn/` | K-Nearest Neighbors — classify/regress by proximity |
| 5 | [Decision Trees](05_decision-trees/) | `05_decision-trees/` | Tree-based models for classification and regression |
| 6 | [Random Forest](06_random-forest/) | `06_random-forest/` | Ensemble of decision trees |

### Future Topics

| Topic | Folder | Description |
|---|---|---|
| [SVM](svm/) | `svm/` | Support Vector Machines — find optimal decision boundaries |
| [Naive Bayes](naive-bayes/) | `naive-bayes/` | Probabilistic classifiers based on Bayes' theorem |
