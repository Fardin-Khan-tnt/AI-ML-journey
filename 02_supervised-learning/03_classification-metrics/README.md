# 03. Classification Metrics

## What You'll Learn

- Confusion matrix (TP, TN, FP, FN)
- Accuracy, Precision, Recall, F1-score
- When accuracy is misleading (imbalanced classes)
- ROC curve and AUC
- `classification_report`
- Choosing metrics for your specific problem

## Why Separate from Algorithms?

These metrics apply to **all classifiers**: Logistic Regression, KNN, Decision Trees, Random Forest, SVM, Naive Bayes. By learning them here, you can evaluate any classifier you build later.

---

## Applies To

Use these metrics for:
- ✅ Logistic Regression
- ✅ KNN Classification
- ✅ Decision Tree Classification
- ✅ Random Forest Classification
- ✅ SVM Classification
- ✅ Naive Bayes
