# 02. Logistic Regression

A linear model for classification — despite the name, it predicts class probabilities, not continuous values.

This is the **second step** — transition from regression to classification problems.

## What You'll Learn

- Binary classification (two classes)
- Multiclass classification (one-vs-rest, multinomial)
- Sigmoid function and decision boundary
- Regularization (`C` parameter)
- `predict_proba()` for class probabilities
- Log loss / cross-entropy
