# NumPy

**Numerical Python** — the foundation for scientific computing in Python.

NumPy provides fast N-dimensional arrays and mathematical functions. It's the base for Pandas, Matplotlib, Scikit-learn, TensorFlow, and most data science libraries.

## Topics Covered

1. **Creating Arrays** — from lists, `zeros`, `ones`, `arange`, `linspace`
2. **Indexing and Slicing** — row/column access, reversing
3. **Reshaping** — `reshape`, `flatten`, transpose
4. **Math Operations** — element-wise arithmetic (scalar and array-to-array)
5. **Math Functions** — `sqrt`, `exp`, `log`, `sin`, rounding, sorting
6. **Comparison Operations** — boolean arrays, conditional replacement
7. **Broadcasting** — operations on arrays of different shapes
8. **Statistical Functions** — `mean`, `median`, `std`, `sum` with `axis`
9. **Boolean Indexing** — filtering with conditions, `np.where`
10. **Stacking and Splitting** — `hstack`, `vstack`, `concatenate`, `split`
11. **Random Number Generation** — modern `default_rng` and legacy `np.random`
12. **Linear Algebra** — dot product, matrix multiplication, determinant, inverse
13. **View vs Copy** — understanding when data is shared vs independent
14. **Performance** — NumPy vs Python lists speed comparison

Ends with a **Cheat Sheet** for quick reference.
