# Matplotlib

The fundamental plotting and visualization library for Python.

Matplotlib provides a MATLAB-like interface for creating static and interactive plots. It works seamlessly with NumPy and Pandas, and is the base for higher-level libraries like Seaborn.

## Topics Covered

1. **Figure and Axes Architecture** — pyplot vs object-oriented approach
2. **Basic Line Plots** — single and multiple lines, grid
3. **Customizing Plots** — colors, line styles, markers, hex codes
4. **Scatter Plots** — basic scatter, varying color and size, colormaps
5. **Bar Charts** — vertical, horizontal, grouped bar charts
6. **Histograms** — single and overlapping distributions
7. **Subplots** — multiple plots in one figure (`plt.subplots`)
8. **Working with Pandas** — plotting directly from DataFrames
9. **Annotations and Text** — arrows, text boxes, reference lines, legends
10. **Plot Styles and Themes** — built-in styles (`ggplot`, `seaborn`, `dark_background`)
11. **Pie Charts** — proportions with explode and percentage labels
12. **Saving Figures** — PNG, PDF with `savefig`
