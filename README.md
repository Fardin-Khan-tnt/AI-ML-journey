# AI & Machine Learning Notes

Personal notes and code examples for learning AI and Machine Learning with Python.

These notebooks are designed to be:
- **Beginner-friendly** — learn concepts from scratch
- **Runnable** — execute code interactively in Jupyter
- **Searchable** — quickly find functions and patterns
- **Shareable** — clean enough to share with others

---

## How to Use

1. Clone this repository
2. Open any notebook in Jupyter or VS Code
3. Run the cells from top to bottom
4. Each notebook ends with a **Cheat Sheet** for quick reference
