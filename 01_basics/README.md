### ML Fundamentals (~1.5 hr)

Before diving into libraries and algorithms, understand the core concepts that power all machine learning.

**What You'll Learn:**

Machine Learning is the science of building systems that learn from data. This section covers the foundational concepts:

- **What is Machine Learning?** — An overview of ML as a field, why it's important, and how it differs from traditional programming.
- **Supervised vs Unsupervised Learning** — Supervised learning uses labeled data to make predictions (e.g., predicting house prices). Unsupervised learning finds patterns in unlabeled data (e.g., customer segmentation).
- **Regression vs Classification** — Regression predicts continuous values (e.g., temperature). Classification predicts categories (e.g., spam or not spam).
- **Features vs Target** — Features are the input variables your model learns from. The target is what you want to predict.
- **Train / Validation / Test Split** — How to split your data into training (learn), validation (tune), and test (evaluate) sets to ensure your model generalizes well.
- **Overfitting vs Underfitting** — Overfitting means your model memorizes training data but fails on new data. Underfitting means your model is too simple to capture patterns. Learning to balance is key.
